# 隐私与数据流

适用于 `0.2.0`。这是软件行为说明；自行部署中继时，运营者还需要说明自己的日志、备份和保存政策。

## 本机读取什么

Mac App 从当前用户的 Codex 数据库、未读记录和会话日志中计算任务状态，调用已安装的 Codex App 获取额度。日志解析在本机完成；上传的是经过字段筛选的展示快照，不上传完整对话日志。任务标题本身可能包含敏感信息，请在连接中继之前确认能接受这一点。

启用音乐同步后，App 读取当前播放器的歌名、歌手、专辑、播放状态及进度。获取歌词时，App 会直接向网易云音乐的公开接口发送歌名和歌手，并按歌曲 ID 请求歌词；请求方 IP 也会被该服务看到。关闭音乐同步后，网页隐藏音乐区域。

添加中转站后，完整 API Key 存在当前 Mac 的登录钥匙串。额度查询由 Mac 直接携带 Key 请求用户配置的 Sub2API 站点；该站点及其运营者可以看到请求和完整 Key。

启用自动检查更新时，App 启动时及每小时访问 GitHub 发行版的更新源；下载更新也通过 GitHub。请求包含常规网络元数据和版本信息，不携带配对令牌、中转站 Key 或任务内容。可在“关于”界面关闭自动检查，手动检查仍会联网。

## 数据存在哪里

| 位置 | 内容 |
| --- | --- |
| Mac 登录钥匙串 | 本机管理口令、中转站 Key、各中继地址对应的设备凭据 |
| Mac 当前用户的应用支持目录 `iPadControl` | 服务开关、中继地址、站点信息、Key 的 ID 和备注、快捷项目配置、配对备注、权限和撤销记录；脚本路径和 Shell 命令也在这里 |
| 浏览器站点存储 | 当前站点的网页配对令牌，以及常亮、页面位置等展示偏好 |
| 中继 SQLite 数据库 | 设备名、设备/会话凭据的摘要、配对码摘要及期限、网页 ID、备注、UA、访问时间和控制权限 |
| 中继进程内存 | 任务、额度、快捷项目及音乐快照，短时控制请求和回执 |

应用支持目录位于 `~/Library/Application Support/iPadControl/`。配置默认使用当前用户可访问的文件权限；它不是加密保险箱。不要在 Shell 命令里直接写入长期密钥，也不要把该目录打进发行包。

中继保存凭据的 SHA-256 摘要，不把设备令牌或网页令牌的明文写入数据库。但是令牌仍会经过中继请求链路，浏览器也需要保存自己的会话令牌。HTTPS 保护传输，不改变中继自身的信任权限。

## 局域网与公网的区别

仅使用本地看板时，网页直接访问 Mac 的原生服务，配对和展示不经过公网中继。本地 HTTP 没有传输加密，只适合可信、可互通的局域网；同网段中的攻击者可能窃听或篡改通信。不能把本地 HTTP 端口直接映射到公网。

配置公网中继后，Mac 会向该地址上传展示快照。中继和从中继加载的网页代码均在信任范围内：

- 任务标题、任务 ID、状态、额度、Key 备注、快捷项目名称和图标、音乐信息及歌词对中继可见。
- 完整中转站 Key、快捷项目中的脚本路径、Shell 命令及脚本输出不属于展示快照。
- 中继运营者仍可能记录请求元数据；本项目无法控制其反向代理、系统监控或备份。

**当前协议不是端到端加密，也没有端到端签名的控制指令。** Mac 会再次检查本机保存的网页权限，但公网 `screenId` 来自中继。某个网页获准控制后，恶意或被入侵的中继仍可能冒用该网页 ID 发起其权限范围内的操作。中继也能替换它提供的 JavaScript，从浏览器侧读取令牌或改变行为。因此只应连接自己管理或充分信任的中继。

## 权限与删除

新配对和升级前尚未明确授权的网页默认只读。只读仍允许查看快照及刷新额度；需要在 Mac App 中开启该网页的控制权限，才可打开任务、操作音乐或执行已配置快捷项目。控制权限覆盖这些操作，不是逐项目授权。

在 Mac App 中撤回控制权限会阻止新的控制操作；已经开始的脚本不会因此自动停止。踢下线会撤销该网页会话，共享该令牌的标签页一起失效；浏览器可能在下一次请求前仍显示旧画面。已被截图、下载或记录的数据无法远程收回。

清除浏览器站点数据可以删除浏览器中的令牌。卸载 App 不会自动清除应用支持目录、钥匙串、登录项或中继数据库；处理这些内容前，应停止后台并备份需要保留的配置。中继重启会清空进程内快照，但数据库和外部日志、备份不会随之删除。

安全边界和漏洞报告方式见 [SECURITY.md](SECURITY.md)。

## 安装身份

Mac 会读取本机硬件标识，在 `installation.json` 中仅保存其 SHA-256 摘要及随机的钥匙串账户后缀，不向服务器上传硬件标识或摘要。用它识别跨 Mac 复制的配置，隔离旧配对、控制授权和运行快照；中转站 Key、设置与快捷项目保留。首次升级前已经存在的旧副本没有基线，不能自动区分。
