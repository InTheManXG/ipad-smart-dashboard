# 安全说明

`0.1.0-beta.3` 是开源测试版本，目前只有本机与 CI 环境的验证记录。它没有独立安全审计，也不应被当作隔离不可信用户或不可信中继的远程管理系统。

## 未公证测试包

文件名含 `unnotarized` 的 App 使用 ad-hoc 签名，没有 Apple 颁发的开发者身份签名和 Apple 公证，不能宣称通过正式 Gatekeeper 验收。发布 SHA-256 清单仅用于检查下载一致性，不提供独立的发布者身份证明。

用户必须自行信任来源，并在系统提供时，仅为该 App 选择“仍要打开”。不应关闭全局 Gatekeeper、清除隔离属性或用终端绕过；受管 Mac 不允许时应停止。安装步骤见 [UNNOTARIZED_INSTALL.md](UNNOTARIZED_INSTALL.md)。ad-hoc 更新可能重新触发钥匙串授权，不能通过放宽整个钥匙串权限规避。

## 信任边界

Mac App 以登录用户身份运行，不使用 App Sandbox。用户配置的应用、脚本、解释器和 Shell 命令拥有该用户的权限。网页不能提交任意命令文本，只能请求执行 Mac 上已经保存的项目 ID；配置恶意脚本仍然可以破坏文件或泄露数据。

新配对和旧版未明确授权的网页默认只读，授权与踢下线由 Mac App 管理。中继检查会话权限，Mac 还检查本地保存的权限；文件缺失、损坏或找不到授权 ID 时不授予控制。撤回权限和踢下线会阻止后续操作，但不会回滚已经开始的任务或终止其派生进程。

公网中继可读取展示快照，并提供浏览器执行的静态 JavaScript。当前协议没有端到端加密或端到端命令签名；获准控制的 `screenId` 可被恶意中继冒用。本地双重检查可以阻止中继给任意新 ID 自行授权，不能证明请求确实来自那个浏览器。使用不可信中继时，仅保持只读也不能保护展示数据的机密性。

详细数据清单见 [PRIVACY.md](PRIVACY.md)。

## 已有防护及限制

- 配对码为随机 8 位码，10 分钟有效、单次使用；网页会话有效期为 30 天。局域网和公网分别管理配对，同一浏览器共享令牌的标签页不算独立身份。
- 公网按设备隔离快照和会话，凭据摘要保存在数据库。配对、请求大小和调用频率有限制，但不能替代入口层的抗滥用和容量管理。
- 任务打开只接受当前快照中的任务 ID；音乐控制仅接受固定动作，并检查曲目标识、期限及回执。
- 快捷项目执行前重新校验本机配置和文件；一次运行一个项目，直接进程最长运行约 5 分钟。没有进程树沙箱，任务自行启动的后台进程可能继续运行。
- 公网只允许 HTTPS 根地址，本机调试可使用回环 HTTP。局域网看板使用 HTTP，必须位于可信网络；不要对公网转发 18088 端口。
- App 的音乐兼容组件使用 macOS 媒体接口及系统 Perl；该接口可能随系统升级变化。它不代表已经通过 App Store 审核。

旧 Python `legacy` 模式仍保留供历史兼容，其共享管理口令不具备逐网页授权。新安装应使用默认 `pairing` 模式，生产反代不应暴露旧模式。

## 运营建议

部署中继时使用有效 HTTPS 证书，并保持 Python 基础镜像、反向代理和宿主机的安全更新。保持默认回环端口绑定、非 root 容器及只读根文件系统；保存数据库的卷和备份应限制访问。不要记录认证头、请求体或配对码。

不要把个人钥匙串导出文件、配对数据库、浏览器令牌、真实 Key、Shell 私密参数或设备配置提交到仓库。公开问题和日志前，删除任务标题、设备名、域名、IP、UA 和文件路径中不希望公开的信息。

## 报告漏洞

请使用项目 GitHub 仓库 **Security → Report a vulnerability** 的私密报告入口；运营者需要先开启该功能。若入口不可用，不要把可利用步骤、有效令牌或用户数据直接发布到公开 Issue，可先用不含细节的 Issue 请求私密联系渠道。本项目尚未承诺响应时限。

报告应包括受影响版本、必要前置条件、最小复现、影响范围和已做脱敏的证据。只使用自己的设备与部署验证，不探测他人的公开中继。修复、版本公告和兼容范围以仓库中的后续发布记录为准。
